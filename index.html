Our Group

Welcome to our group portfolio. We are developing a Dictionary Application using HTML, CSS, JavaScript, and an external Dictionary API.

The goal of our project is to provide users with a simple and easy-to-use application for searching word definitions.

Our Project

Dictionary Application

Our Dictionary Application allows users to enter a word and search for its definition. The application retrieves information from an external API and displays the result on the webpage.
